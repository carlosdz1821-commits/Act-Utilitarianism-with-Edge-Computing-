## Project Topic
**Edge Computing Security**

Edge computing moves data processing closer to the source of the data, such as IoT devices, instead of relying completely on centralized cloud systems. Although this can reduce latency and improve performance, it can also create security concerns because data and devices are distributed across many locations.

Some major concerns include:
- Increased attack surfaces
- Security of distributed devices
- Data privacy
- Decentralized data storage and processing
- Device authentication and access control

## Ethical Theory
**Act Utilitarianism**

Our group will analyze edge computing security using Act Utilitarianism. This ethical theory focuses on evaluating individual actions based on whether they produce the greatest overall benefit or happiness for the greatest number of people.

For this project, we will examine how security decisions in edge computing affect users, organizations, developers, and other stakeholders. We will consider benefits such as speed, accessibility, and efficiency while also examining possible harms involving privacy, security breaches, surveillance, and compromised devices.

## Research Question

How should organizations make edge computing security decisions under Act Utilitarianism while balancing security, privacy, performance, cost, and convenience?
